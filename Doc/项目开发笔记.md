## 二、硬件资源配置

### 2.1 野火霸道板 V1

#### LED 配置
| LED | 引脚 | 点亮方式 | 当前使用 |
|-----|------|----------|----------|
| 绿灯 | PB5 | **低电平点亮** | ✅ 当前使用 |
| 黄灯 | PA12 | 低电平点亮 | - |
| 红灯 | PA11 | 低电平点亮 | - |

#### 按键配置
| 按键 | 引脚 | 说明 | 当前使用 |
|------|------|------|----------|
| KEY1 | PA0 | 低电平有效 | ✅ 当前使用 |
| KEY2 | PC13 | 低电平有效（有限制） | - |

#### 串口配置
| 串口 | 引脚 | 波特率 | 用途 |
|------|------|--------|------|
| USART1 | PA9(TX)/PA10(RX) | 115200 | 调试串口 |
| USART3 | PB10(TX)/PB11(RX) | 115200 | **板载ESP8266** |

**重要**：霸道板V1 **板载ESP8266模块**，连接在 **USART3 (PB10/PB11)**！

## 三、C8T6 与 ZET6 关键区别

### 3.1 引脚差异

| 模块 | C8T6 | ZET6 (霸道板) | 迁移建议 |
|------|------|---------------|----------|
| LED | PB5 | PB5 | ✅ 相同 |
| 按键 | PA1/PA2/PA3/PA0 | PA0 (KEY1) | 修改引脚 |
| USART1 | PA9/PA10 | PA9/PA10 | ✅ 相同 |
| USART3 | PB10/PB11 | PB10/PB11 | ✅ 相同 |
| I2C1 | PB6/PB7 | PB6/PB7 | ✅ 相同 |
| SPI1 | PA5-PA7 | PA5-PA7 | ✅ 相同 |

### 3.2 迁移要点

1. **LED**：霸道板为低电平点亮
2. **按键**：霸道板使用 PA0 (KEY1)
3. **USART3**：霸道板连接板载ESP8266

## 四、OneNET 配置问题

### 4.1 当前状态
- ❌ OneNET 相关参数**未配置正确**
- 项目**没有跑通**云平台连接

### 4.2 需要配置的内容

```c
// WiFi配置
#define WIFI_SSID       "你的WiFi名称"
#define WIFI_PASS       "你的WiFi密码"

// OneNET平台配置
#define ONENET_SERVER_IP     "mqtts.heclouds.com"
#define ONENET_SERVER_PORT   1883
#define ONENET_PRODUCT_ID    "你的产品ID"
#define ONENET_DEVICE_NAME   "你的设备名称"
#define ONENET_AUTH_INFO     "Token鉴权信息"
```

### 4.3 配置来源
- 登录 [OneNET 平台](https://open.iot.10086.cn/)
- 创建产品 → 创建设备 → 获取设备信息
